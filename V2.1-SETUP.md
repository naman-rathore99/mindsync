# MindSync 2.1 — two-minute text message window

Base: MindSync v2 full project (previous archive). Only `app/us/page.tsx` and the new SQL migration are required for a v2 installation. The original quiz, surprise, links, pairing and streak code remains unchanged.

## Upgrade
1. Back up the existing database and test on a preview branch. If v2 is not deployed yet, follow `V2-SETUP.md` first (including the original `schema.sql` if the sessions table is absent). Do not point the live site at a new database.
2. In Supabase SQL Editor for the existing project, run the whole `supabase/mindsync-v2.1.sql` after `supabase/mindsync-v2.sql`. It does not delete or rewrite existing note rows. Do not rerun the v2 migration by itself afterwards; if necessary run v2.1 again immediately afterward. The new SQL migration is repeatable.
3. Copy the update files into their matching paths, or apply the supplied v2-to-v2.1 patch with `git apply --check ...` before `git apply ...`. Use a clean preview branch based on the v2 code. Do not overwrite any local customisations without review.
4. No new environment variables or npm dependencies. Run `npm install` and `npm run build`, then deploy a Vercel preview. The previous UI still works with the new schema but may show stale edit/delete buttons and may report success when RLS rejects an expired change; deploy the new UI promptly after migrating and test both devices.

## Behaviour
- Text notes are inserted immediately on Send message. The sender has 120 seconds from the original database timestamp to edit title/body or delete the message. Editing doesn't reset the clock. Deleted shared messages disappear for both users on refresh. The countdown is approximate and synced to the database clock; the actual authorization is enforced by Supabase RLS and a database trigger. Existing text notes older than two minutes are locked too.
- No automatic deletion or delayed save. Notes remain locked after expiry. The app's rule does not override account deletion, administrative actions, or infrastructure data loss. Owners can still manually delete game/surprise sessions independently.
- Photo, voice and video notes save upon successful upload and metadata insert, without a waiting period. The previous owner-only caption edit/permanent media removal controls remain available. File selection/recording alone is a preview, not an upload. Media restrictions and 20 MiB/60-second recording limits from v2 remain.
- No realtime chat was added. Tap Refresh space to see partner changes, or reopen the page. All actions require an existing signed-in account. No extra public permissions were granted.
